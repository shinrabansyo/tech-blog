# 260214_アワード'26 プログラミング体験 動かし方メモ

1. sb-builderコマンドが利用できる状態にする
   - [shinrabansyo/penv-manager](https://github.com/shinrabansyo/penv-manager)をインストール
2. CPUが動作する状態にする
   - [shinrabansyo/cpu](https://github.com/shinrabansyo/cpu)をgit cloneして動作する状態にする
   - 詳細は追々
3. sbファイルをビルドしてCPUで動作させる
   - 適当なディレクトリを作成
   - .sbファイルを作成してやりたい操作を記述する
   - sb-builderコマンドでビルド
     - `sb-builder oneshot command.sb build`
     - `sb-builder oneshot test.sb run`
   - エミュレーターで動作確認
     - `c`キーで最後の処理まで実行
     - `s`キーで1行ずつ実行
     - `q`で終了
     - `Control Mode <i> Move Mode <Esc> | Command <Enter> | Up <k> Down <j> Left <h> Right <l> | Auto-Exec <Space> Step <s> Continue <c> | Quit <q>`
