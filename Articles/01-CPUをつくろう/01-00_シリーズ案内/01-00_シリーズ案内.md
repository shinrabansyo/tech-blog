# 「CPUをつくろう」シリーズ案内

> タグ: CPU自作 / 学習ロードマップ / Chisel / Veryl / FPGA

このシリーズでは、小さな組み合わせ回路から始め、独自命令を実行するCPU、周辺機器、FPGAでの実機動作へ進みます。森羅万象プロジェクトが2023年から開発してきた順序を参考にしていますが、初学者が一段ずつ理解できるよう、記事の順序は組み直しています。

## 読者として想定している人

- 日本の高校生・大学生
- プログラミングや情報工学を学び始めた人
- CPUの中で何が起きているか、手を動かして知りたい人
- 論理回路、Scala、Chiselをまだ知らない人

数学や電気回路の詳しい知識は前提にしません。2進数や論理演算も必要になった記事で説明します。

## 実際の開発との関係

開発はきれいな一本道ではありません。実機で問題が見つかって前の回路へ戻ることも、カンファレンスの展示を目標に複数の機能をまとめて進めることもありました。

大きな区切りは次の通りです。

| 時期 | 開発の区切り |
| --- | --- |
| 2023年8月～2024年2月 | Chiselで加算器、命令実行、分岐、メモリ、UARTを実装 |
| 2024年3月～11月 | SPI、GPIO、アセンブラ、呼び出し規約、FPGA実機動作を拡張 |
| 2024年12月～2025年4月 | Chisel版を残しながらVerylへ段階的に移植 |
| 2025年4月～7月 | 映像出力、SDカード読み出し、SDカードからの起動 |
| 2025年秋～2026年2月 | FAT16、コンパイラ、キャッシュ、インターコネクト、パイプライン、malloc |

この表は作業履歴とコミット履歴をまとめたものです。「その時点ですべて完成した」という意味ではありません。試作、デバッグ、仕様変更を含みます。

## サンプルコードの考え方

記事用コードは、完成版CPUをそのまま切り出したものではありません。学ぶ内容を1つか2つに絞った教材です。

たとえばCPU-3は森羅万象CPUの48 bit命令形式を使いますが、4命令しか実装しません。完成版との差を毎回明記し、記事を読み終えた段階で「どこまで動くのか」が分かるようにします。

## 用語と表記

- bit幅は `8 bit`、`32 bit`のように書きます。
- 2進数には `0b`、16進数には `0x`を付けます。
- `r4`は4番目のレジスタ、`r[rs1]`は命令中の `rs1` が指すレジスタを表します。
- ISAはInstruction Set Architecture、CPUとソフトウェアの間で決める命令の仕様です。
- ChiselとVerylはどちらもハードウェアを記述するための言語ですが、設計の表し方とツール構成が異なります。

最初から順に読む場合は「01-01 CPU自作の準備」へ進んでください。今回の執筆範囲は2026年2月までです。ホームページ制作とISA v2以降は含みません。
