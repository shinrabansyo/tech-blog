# 計算を選べるALUをつくる

> タグ: CPU自作 / Chisel / ALU / 選択回路 / 論理演算

こんにちは、森羅万象プロジェクトです。

前回は足し算だけを行う加算器を作りました。今回は、番号を1つ与えると計算方法を選べるALUを作ります。

ALUはArithmetic Logic Unitの略で、日本語では算術論理演算装置などと呼ばれます。「算術」は加算や減算、「論理」はAND、OR、XORなどのbitごとの演算です。

## 今回の入出力

ALUには、計算する2つの値と、計算方法を表す `command` を入力します。

```text
 command ─┐
 a ───────┼─ [ ALU ] ── out
 b ───────┘
```

この教材では、次の番号を使います。

| command | 演算 | 例（a=10、b=3） |
| ---: | --- | ---: |
| 1 | 加算 `a + b` | 13 |
| 2 | 減算 `a - b` | 7 |
| 3 | AND `a & b` | 2 |
| 4 | OR `a \| b` | 11 |
| 5 | XOR `a ^ b` | 9 |
| その他 | 既定値 | 0 |

この `command` はALUの内部で使う教材上の番号です。次回登場するCPU命令の `opcode` と同じものではありません。

## AND、OR、XOR

10と3を4 bitの2進数で書くと、`1010`と`0011`です。論理演算は、同じ位置にあるbit同士を計算します。

```text
       1010
       0011
AND -> 0010  (2)
 OR -> 1011  (11)
XOR -> 1001  (9)
```

- ANDは両方が1のbitだけ1
- ORは少なくとも片方が1なら1
- XORは片方だけが1なら1

ANDは必要なbitだけを取り出すマスク処理などに使われます。ORは特定のbitを1にし、XORは特定のbitを反転するときにも使えます。

## Chiselで選択回路を書く

`CPU-2/src/main/scala/core/Alu.scala` の中心は次の部分です。

```scala
io.out := MuxLookup(io.command, 0.U)(Seq(
  AluCommand.add -> (io.a + io.b),
  AluCommand.sub -> (io.a - io.b),
  AluCommand.and -> (io.a & io.b),
  AluCommand.or  -> (io.a | io.b),
  AluCommand.xor -> (io.a ^ io.b)
))
```

`Mux`はmultiplexer、つまり複数の入力から1つを選ぶ回路です。`MuxLookup`は、`command`の値に対応する式を選びます。どの番号にも当てはまらなければ、第2引数の `0.U` を出力します。

番号には名前を付けています。

```scala
object AluCommand {
  val add = 1.U(3.W)
  val sub = 2.U(3.W)
  val and = 3.U(3.W)
  val or  = 4.U(3.W)
  val xor = 5.U(3.W)
}
```

`1.U`をコード中へ何度も直接書くより、`AluCommand.add`と書くほうが意味を読み取りやすくなります。

## ここにもまだ記憶はない

今回のALUも組み合わせ回路です。`command`、`a`、`b`の現在値だけで `out` が決まります。前に計算した結果は覚えていません。

CPUにするには、少なくとも次の部品が必要です。

- 命令を置くメモリ
- 次に読む命令の位置を覚えるプログラムカウンタ
- 計算途中の値を覚えるレジスタ
- 命令を各信号へ分けるデコーダ
- 今回作ったALU

次回はこれらを最小限だけ組み合わせます。

## テストする

`CPU-2/src/test/scala/core/TopTest.scala` では、`a=10`、`b=3`を保ったまま `command` を切り替えます。

```scala
dut.io.a.poke(10.U)
dut.io.b.poke(3.U)

dut.io.command.poke(1.U)
dut.io.out.expect(13.U)

dut.io.command.poke(2.U)
dut.io.out.expect(7.U)
```

同じ入力線でも、選択信号が変わると通る回路が変わります。これが、CPUが命令に応じて異なる演算を行う基本です。

```console
cd CPU-2
sbt test
```

テストが通ったら、未定義の `command=0` や `command=6` で0が出ることも試してみてください。

## 「命令」は次回から

今回は分かりやすさのために `command` をテストから直接入力しました。実際のCPUでは、メモリから読んだ命令をデコーダが分解し、その結果からALUへ命令番号を渡します。
