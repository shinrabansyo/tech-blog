# 加算器をつくる――最初のデジタル回路

> タグ: CPU自作 / Chisel / 加算器 / 組み合わせ回路 / bit

こんにちは、森羅万象プロジェクトです。

前回はChiselを動かす準備をしました。今回は、2つの数を足す8 bit加算器を作ります。まだCPUではありませんが、CPUの中で計算を担当するALUの材料になります。

この記事を終えると、次のことが分かります。

- Chiselの `Input`、`Output`、`UInt`
- 組み合わせ回路とは何か
- bit幅を超えた計算結果がどうなるか
- テストで回路の動作を確かめる方法

## 8 bitで表せる範囲

bitは0か1のどちらかを表す情報の単位です。8 bitの符号なし整数は、

```text
00000000 = 0
11111111 = 255
```

の範囲を表せます。256通りの組み合わせがあるので、範囲は0から255です。

今回作る回路には、8 bitの入力を2本、8 bitの出力を1本用意します。

```text
 a ──┐
     ├─ [ 8 bit 加算器 ] ── out
 b ──┘
```

## Chiselで加算器を書く

`CPU-1/src/main/scala/Adder.scala` を見てください。

```scala
package core

import chisel3._

class Adder extends Module {
  val io = IO(new Bundle {
    val a   = Input(UInt(8.W))
    val b   = Input(UInt(8.W))
    val out = Output(UInt(8.W))
  })

  io.out := io.a + io.b
}
```

短いコードですが、役割ごとに読んでみましょう。

### ModuleとIO

`Module`は回路の部品です。`IO(new Bundle { ... })` の中に、その部品の外側とつながる信号をまとめます。

```scala
val a = Input(UInt(8.W))
```

は、`a`という8 bitの符号なし整数入力を表します。`UInt`はUnsigned Integer、`8.W`は幅が8 bitという意味です。

```scala
val out = Output(UInt(8.W))
```

は8 bitの出力です。

### 接続を表す :=

```scala
io.out := io.a + io.b
```

`:=`はChiselで信号を接続するときに使います。この回路には状態を記憶する部品がないので、`a`か`b`が変わると、それに応じて`out`も変わります。このように、現在の入力だけで出力が決まる回路を組み合わせ回路と呼びます。

## オーバーフローを観察する

`3 + 5`の結果は8なので、8 bitに収まります。

```text
00000011
+00000101
---------
 00001000
```

では、`250 + 10`はどうでしょうか。答えの260を2進数で表すには9 bit必要です。

```text
 11111010  (250)
+00001010  (10)
---------
100000100  (260)
```

今回の `out` は8 bitしかありません。そのため、左端の9 bit目は出力へ入りません。残る `00000100`、つまり4が出力されます。これは「計算が間違った」のではなく、回路の出力幅を8 bitに決めた結果です。

桁上がりも必要なら、9 bitの出力を用意するなど、仕様を変える必要があります。ハードウェア設計では「値の意味」と「信号の幅」をセットで考えます。

## テストを書く

`CPU-1/src/test/scala/Top.scala` には2つのテストがあります。

```scala
test(new Adder) { dut =>
  dut.io.a.poke(3.U)
  dut.io.b.poke(5.U)
  dut.io.out.expect(8.U)
}
```

- `dut`はDevice Under Test、つまりテスト対象の回路
- `poke`は入力へ値を与える操作
- `expect`は出力が期待値と同じか確かめる操作

もう一つのテストでは、オーバーフロー時に下位8 bitだけが残ることを確かめます。

```scala
dut.io.a.poke(250.U)
dut.io.b.poke(10.U)
dut.io.out.expect(4.U)
```

加算器は組み合わせ回路なので、クロックを進める `clock.step()` は必要ありません。後でレジスタを使う回路では、クロックが重要になります。

## 実行する

```console
cd CPU-1
sbt test
```

両方のテストが成功すれば完成です。次のように値を変えて、結果を予想してから試すのもおすすめです。

- `0 + 0`
- `127 + 1`
- `255 + 1`
- `200 + 100`

## 今回作ったものの位置づけ

加算器だけでは命令を読めず、結果を記憶することもできません。そのため、これ単体をCPUとは呼びません。けれどもCPUを分解していくと、このような小さな回路の組み合わせになります。
