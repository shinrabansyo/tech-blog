# 条件分岐を加えて、CPUに判断と繰り返しをさせよう

> タグ: CPU自作 / Chisel / ISA / 条件分岐 / プログラムカウンタ

前回までのCPUは、命令を上から順に実行するだけでした。計算はできても、「0になるまで繰り返す」「値が同じなら別の処理へ進む」といったプログラムは書けません。

この記事では森羅万象CPUに条件分岐命令を加えます。開発では2023年10月ごろに `beq` が入り、その後 `bne`、`blt`、`ble` などへ広がりました。

## 分岐はPCの行き先を選ぶ処理

PC（Program Counter）は、次に読む命令のアドレスを持つレジスタです。森羅万象CPUの命令は1個6 byteなので、通常は次のように進みます。

```text
0 → 6 → 12 → 18 → ...
```

分岐条件が成立したときだけ、PCへ別のアドレスを入れます。

```text
条件が偽: PC ← PC + 6
条件が真: PC ← PC + 符号拡張した変位
```

## まずはbeq

`beq` は branch if equal、つまり2つの値が等しければ分岐する命令です。疑似コードで表すと次の処理です。

```text
if (r[rs1] == r[rs2]) {
    PC = PC + sign_extend(immediate)
} else {
    PC = PC + 6
}
```

ハードウェアでは、レジスタの値を比較した結果でPCへ書く値を切り替えます。Chiselなら `when` と `otherwise`、または `Mux` で表せます。

```scala
when(registers(rs1) === registers(rs2)) {
  pc := pc + signedImmediate
}.otherwise {
  pc := pc + 6.U
}
```

実際のCPUでは、命令のデコードや書き戻しも同時に扱います。ここでは「比較結果によってPCを選ぶ」という中心だけを抜き出しています。

## 比較命令を増やす

開発では次の条件分岐を実装しました。

| 命令 | 分岐する条件 |
| --- | --- |
| `beq` | 2つの値が等しい |
| `bne` | 2つの値が等しくない |
| `blt` | 左の値が右の値より小さい |
| `ble` | 左の値が右の値以下 |

大小比較では、同じ32 bitの並びでも符号付きと符号なしで意味が変わります。たとえば `0xffffffff` は、符号付きなら -1、符号なしなら 4,294,967,295 です。命令仕様がどちらを求めているかを確認してから比較回路を選びます。

## 無条件分岐も作れる

`r0` は常に0を読むレジスタです。したがって、次の比較は必ず成立します。

```text
beq r0, (r0, r0) -> loop
```

これは「無条件で `loop` へ移動する」命令として使えます。専用命令を増やさず、既存の条件分岐とゼロレジスタを組み合わせる考え方です。

## ループを書いてみる

次は、`r4` を3から0まで減らすイメージです。

```text
addi r4 = r0, 3

@loop
subi r4 = r4, 1
bne  r0, (r4, r0) -> loop
```

1. `r4` に3を入れる
2. `r4` から1を引く
3. `r4 != 0` なら `loop` に戻る
4. 0になったら次へ進む

ここに登場する `@loop` は、後の記事で作るアセンブラのラベルです。CPUがラベル名を理解するわけではありません。アセンブラが現在のPCからラベルまでの相対変位へ変換します。

## 分岐成立時に戻り先も保存する

森羅万象CPUのv1命令では、分岐が成立すると分岐先へ移動すると同時に、`rd` へ `PC + 6` を保存できます。このプロジェクト固有の仕様です。

```text
r[rd] ← PC + 6
PC    ← PC + sext(imm)
```

`rd` に `r1` を選べば、戻り先を残した関数呼び出しにも使えます。`r0` を選べば書き込みは捨てられ、普通の分岐として使えます。関数呼び出しは02-04で扱います。

## テストで見るべき点

分岐はPCを書き換えるため、失敗するとプログラム全体が違う場所へ進みます。最低でも次を別々にテストします。

- 条件が真なら分岐先へ移動する
- 条件が偽なら6 byte先へ進む
- 分岐したときだけ戻り先が `rd` に入る
- `rd = r0` ではゼロレジスタが変化しない
- 自分自身や後方へ分岐できる
- 符号付き比較で負数を正しく扱える

波形では、比較に使った2つの値、分岐条件、分岐先、更新前後のPCを並べると原因を追いやすくなります。
